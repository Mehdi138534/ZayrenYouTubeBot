# 🤖 ZayrenYouTubeBot

بات تلگرامی که **ویدیوهای جدید (لانگ و شورت)** کانال یوتیوب [@Zayren666](https://www.youtube.com/@Zayren666) را خودکار به کانال تلگرام [@Zayren6666](https://t.me/Zayren6666) می‌فرستد.
روی **GitHub Actions** اجرا می‌شود؛ پس **رایگان است و به سرور نیاز ندارد**.

## ✨ قابلیت‌ها
- ارسال خودکار ویدیوی جدید با تصویر کاور، دکمه‌ی تماشا و دکمه‌ی کانال
- تشخیص **لانگ** و **شورت** (متن و لینک متفاوت)
- **رفتار رندوم**: تیتر، جمله، درخواست‌ها، متن دکمه‌ها و پایان پیام هر بار فرق می‌کند (و تکراری پشت‌سرهم نمی‌آید)
- **معرفی خودکار بات** در کانال (یک بار، و پین می‌شود)
- پست‌های فان تصادفی (متن یا نظرسنجی) گاهی و فقط ساعت‌های روز (به وقت تهران)
- دستورهای پی‌وی: `/start` `/help` `/about` `/latest` `/fun`
- اجرای اول: **آخرین ویدیوی لانگ و آخرین شورت** را می‌فرستد (قبلاً هیچ‌چیز نمی‌فرستاد!)
- ضد اسپم: ویدیوهای قدیمی‌تر از ۷ روز و بیش از ۵ ویدیو در هر اجرا ارسال نمی‌شود

---

## 🧭 راه‌اندازی از صفر تا صد

### قدم ۱: ساخت بات در تلگرام
1. در تلگرام به [@BotFather](https://t.me/BotFather) برو و `/newbot` بفرست.
2. یک اسم و یک username (باید به `bot` ختم شود) انتخاب کن.
3. **توکن** را که شبیه `123456789:AAH...` است کپی کن. این رمز بات است؛ به کسی نده.

### قدم ۲: بات را ادمین کانال کن (مهم‌ترین قدم!)
1. کانال ← اسم کانال ← **Administrators** ← **Add Administrator**.
2. بات را جستجو و اضافه کن.
3. مطمئن شو دسترسی **Post Messages** روشن است.

> اگر این قدم را انجام ندهی، هیچ پیامی ارسال نمی‌شود. حالا بات خودش این را چک می‌کند و در لاگ‌ها واضح می‌گوید.

### قدم ۳: آپلود پروژه روی گیت‌هاب
1. به [github.com](https://github.com) برو و یک repository جدید بساز (نام: `ZayrenYouTubeBot`، ترجیحاً **Public** تا دقیقه‌های اکشنز نامحدود باشد).
2. همه‌ی فایل‌های این پروژه را در آن آپلود کن (دکمه‌ی **Add file ← Upload files**). پوشه‌ی `.github` را هم حتماً آپلود کن.
3. اگر قبلاً فایل `seen_videos.json` قدیمی در repository بود، پاکش کن (دیگر استفاده نمی‌شود).

### قدم ۴: تعریف Secretها
در repository: **Settings ← Secrets and variables ← Actions ← New repository secret**

| نام Secret | مقدار | اجباری؟ |
|---|---|---|
| `BOT_TOKEN` | توکن BotFather | ✅ بله |
| `TELEGRAM_CHANNEL` | `@Zayren6666` | اختیاری (پیش‌فرض همین است) |
| `YOUTUBE_CHANNEL_ID` | آی‌دی کانال یوتیوب (با `UC` شروع می‌شود) | اختیاری؛ اگر نگذاری از روی `@Zayren666` خودکار پیدا می‌شود |

**پیدا کردن آی‌دی کانال یوتیوب (اگر خواستی):** یوتیوب ← کانال خودت ← About ← Share channel ← Copy channel ID.

### قدم ۵: روشن کردن Actions و اجرای اول
1. تب **Actions** ← اگر پیام فعال‌سازی داد، **Enable** بزن.
2. **Zayren YouTube Bot** ← **Run workflow** ← **Run workflow**.
3. بعد از حدود یک دقیقه، در کانال باید این‌ها را ببینی:
   - 👋 پیام معرفی بات (پین‌شده)
   - 🎬 آخرین ویدیوی لانگ
   - 📱 آخرین شورت

از این به بعد هر ۱۵ دقیقه خودش چک می‌کند و ویدیوی جدید را می‌فرستد.

## 🛠️ دکمه‌های دستی (Run workflow)
- **force_latest**: آخرین لانگ و شورت را دوباره می‌فرستد
- **force_intro**: پیام معرفی را دوباره می‌فرستد

## 🩺 عیب‌یابی
اگر چیزی ارسال نشد، تب **Actions** ← آخرین اجرا ← **Run bot** را باز کن:

| پیام | معنی و راه‌حل |
|---|---|
| `توکن بات اشتباه است` | `BOT_TOKEN` را دوباره از BotFather کپی کن |
| `کانال ... پیدا نشد` | اسم کانال را بررسی کن (`@Zayren6666`) |
| `بات داخل کانال ادمین نیست` | قدم ۲ را انجام بده |
| `دریافت فید یوتیوب ناموفق` | معمولاً موقتی است؛ اجرای بعدی درست می‌شود |
| `ویدیوی جدیدی نیست` | یعنی همه چیز سالم است؛ فقط ویدیوی جدیدی نیامده |

## 📂 ساختار پروژه
```
bot.py                         ← کد اصلی بات
requirements.txt               ← کتابخانه‌ها
.github/workflows/youtube-bot.yml  ← زمان‌بندی اجرا روی GitHub Actions
bot_state.json                 ← حافظه‌ی بات (خودکار ساخته می‌شود)
tests/test_bot.py              ← تست‌ها (python tests/test_bot.py)
```

## ✏️ شخصی‌سازی
همه‌ی متن‌های رندوم بالای `bot.py` هستند (`HEADERS_LONG`، `HOOKS`، `FUN_TEXTS` و ...). هر چیزی دوست داری اضافه یا کم کن.
برای خاموش کردن پست‌های فان، در workflow متغیر `DISABLE_FUN_POSTS: "1"` را اضافه کن.

## ℹ️ نکته‌ها
- دستورهای پی‌وی (`/start` و...) به‌خاطر اجرای هر ۱۵ دقیقه، با حداکثر ۱۵ دقیقه تأخیر جواب داده می‌شوند.
- گیت‌هاب بعد از ۶۰ روز بی‌فعالیتی اجرای زمان‌بندی‌شده را متوقف می‌کند؛ بات برای جلوگیری از این، هر ~۲۰ روز خودش یک commit کوچک می‌زند.
- زمان‌بندی گیت‌هاب گاهی چند دقیقه دیر می‌شود؛ طبیعی است.
